### 2. `weather_handler.py`
**Функционал**: обработка `/weather`.
```python
@router.message(Command("weather"))
async def handle_weather_request(message: Message):
    user_id = message.from_user.id
    loc = central_db.get_default_location(user_id)
    if not loc:
        await message.answer("Сначала добавьте локацию: /locations")
        return

    with safe_task("weather_request", user_id):
        if local_db_weather.has_fresh_data(loc.lat, loc.lon):
            data = local_db_weather.get_weather(loc.lat, loc.lon)
        else:
            raw = WeatherAPIClient().fetch_current(loc.lat, loc.lon)
            validator.validate_weather_response(raw)  # ← кастомная валидация
            local_db_weather.save_weather(loc.lat, loc.lon, raw)
            data = raw

        text = weather_presenter.format_for_telegram(data, loc.display_name)
        await message.answer(text, parse_mode="HTML")
```
**Зависимости**: `local_db_weather.py`, `central_db.py`, `api_client.py`, `weather_presenter.py`.

## 🔷 Что реализовать в первую очередь?

1. **`central_db.py`** — таблицы `users` и `user_locations`.
2. **`coordinate_manager.py`** — `LocationResolver` с геокодером.
3. **`location_fsm.py`** — базовый FSM для добавления локации.
4. **`weather_handler.py`** — минимальный `/weather` с кэшем.

После этого — тесты и безопасность (шаблоны, санитизация).
