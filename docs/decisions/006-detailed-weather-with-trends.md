# 006. Детальный прогноз погоды с трендами

## Статус
Принято

## Контекст
Простой прогноз температуры недостаточен для метеочувствительных пользователей.

## Решение
Добавить:
- Давление, влажность, ветер, видимость,
- Тренды изменений за час (dT/dt, dP/dt),
- Эмодзи для наглядности.

## Последствия
- ✅ Повышенная информативность,
- ✅ Подготовка к подключению OpenWeather One Call API,
- 🔄 Заменить симуляцию на реальные данные.
