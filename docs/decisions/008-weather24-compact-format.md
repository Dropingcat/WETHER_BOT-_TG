# 008. Компактный формат 24-часового прогноза

## Статус
Принято

## Контекст
Исходный текстовый прогноз не помещался на экран смартфона:
- Длинные слова ("Пасмурно", "Солнечно"),
- Много параметров в строке,
- Переносы ломали читаемость.

## Решение
Перейти на компактный формат в одну строку на час:
- 🌡️+8°C — температура,
- 💧0.2 — осадки в мм/ч,
- 📉758 — давление,
- 💨СЗ3 — ветер (направление + скорость).

## Последствия
- ✅ Умещается на мобильных экранах,
- ✅ Сохраняется ключевая метеоинформация,
- ✅ Подготовка к реальным данным из OpenWeather API,
- 🔄 При подключении API — заменить симуляцию осадков на реальные значения.
