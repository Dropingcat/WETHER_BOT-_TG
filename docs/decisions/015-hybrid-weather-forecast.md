# 015. Гибридный прогноз: локальные + глобальные параметры

## Статус
Принято

## Контекст
Региональные модели (ECMWF, ICON) точны для Т/P/осадков, но не предоставляют видимость.
Глобальные модели (OpenWeather, GFS) дают полный набор, но с меньшей точностью.

## Решение
Использовать гибридный подход:
- Локальные параметры → из ближайшей региональной модели,
- Глобальные параметры → из OpenWeather или GFS.

## Последствия
- ✅ Повышенная точность ключевых параметров,
- ✅ Сохранение полноты данных,
- 🔄 Требуется объединение данных из нескольких источников.
