# 005. Обратный геокодинг с эмодзи-префиксом

## Статус
Временно

## Контекст
Геопозиции выглядят как "55.7558, 37.6176" — неинформативно.

## Решение
Использовать заглушку обратного геокодинга, возвращающую "Страна, Местность".
Добавлять случайный эмодзи из набора из 10.

## Последствия
- ✅ Улучшен UX: локации читаемы,
- ✅ Визуальное разнообразие,
- 🔄 Заменить заглушку на OpenCage/Nominatim,
- 🔄 Связать эмодзи с климатом (например, ❄️ для холодных регионов).
