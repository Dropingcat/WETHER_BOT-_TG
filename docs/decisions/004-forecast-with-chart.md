# 004. Прогноз на 5 дней с графиком через matplotlib

## Статус
Временно

## Контекст
Нужно визуализировать 5-дневный прогноз. Варианты:
- Генерация на внешнем сервере (требует бэкенд),
- Использование готового изображения из API (требует ключ),
- Локальная генерация через `matplotlib`.

## Решение
Использовать `matplotlib` для генерации PNG в памяти.  
Изображение отправляется через `send_photo`.
