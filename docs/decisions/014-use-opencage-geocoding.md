# 014. Геокодинг текстовых локаций через OpenCage

## Статус
Принято

## Контекст
Ранее текстовые локации использовали фейковые координаты (0,0).

## Решение
Использовать OpenCage Geocoder API для получения реальных координат и форматированного названия.

## Последствия
- ✅ Реальные локации вместо заглушек,
- ✅ Поддержка русского языка,
- ❌ Зависимость от внешнего API,
- 🔄 Добавить кэширование и обработку лимитов.
