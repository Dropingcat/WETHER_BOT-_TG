## Модели Open-Meteo

| Модель | Регион | Точность |
|--------|--------|----------|
| `ecmwf_ifs04` | Европа | Высокая |
| `icon_seamless` | Германия | Очень высокая |
| `arome_seamless` | Франция | Очень высокая |
| `harmonie_seamless` | Скандинавия | Очень высокая |
