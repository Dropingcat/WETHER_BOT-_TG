Замените функцию `start` на:

```python
async def start(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """Главное меню с кнопками."""
    buttons = [
        [InlineKeyboardButton("🌤️ Прогноз погоды", callback_data="nav_weather")],
        [InlineKeyboardButton("📍 Управление локациями", callback_data="nav_locations")]
    ]
    await context.bot.send_message(
        chat_id=update.effective_chat.id,
        text="🌤️ <b>Метео-бот</b>\nВыберите действие:",
        reply_markup=InlineKeyboardMarkup(buttons),
        parse_mode=ParseMode.HTML
    )
```

Добавьте обработчик в `bot.py`:

```python
async def main_menu_callback(update: Update, context: ContextTypes.DEFAULT_TYPE):
    """Обработка кнопок главного меню."""
    query = update.callback_query
    await query.answer()
    if query.data == "nav_weather":
        await weather_menu(update, context)
    elif query.data == "nav_locations":
        await show_locations_menu(update, context)

# В main():
app.add_handler(CallbackQueryHandler(main_menu_callback, pattern="^nav_(weather|locations)$"))
```

```markdown
# 003. Интерактивное главное меню с кнопками

## Статус
Принято

Текстовое главное меню неудобно — пользователь не видит, какие команды доступны.

Заменить `/start` на меню с inline-кнопками:
```
